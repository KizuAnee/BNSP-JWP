# Sistem Informasi Manajemen Perpustakaan

Proyek Akhir Uji Kompetensi Sertifikasi BNSP - Skema Junior Web Programming (JWP).

## Deskripsi Aplikasi
Aplikasi berbasis PHP Native dan MySQL untuk mengelola master data buku, anggota, serta pemrosesan transaksi peminjaman dan pengembalian buku lengkap dengan rekapitulasi laporan denda keterlambatan.

## Spesifikasi Teknis
- Bahasa Pemrograman: PHP (Prosedural Terstruktur & Fungsi)
- Basis Data: MySQL / MariaDB (Driver mysqli)
- Front-End Framework: Bootstrap 5 (CDN)
- Web Server: XAMPP (Apache & MySQL)

## Cara Instalasi
1. Salin seluruh direktori proyek ke dalam `htdocs` XAMPP (`htdocs/perpus-app`).
2. Impor berkas `database/manajemen_perpustakaan.sql` melalui phpMyAdmin.
3. Jalankan Apache dan MySQL pada XAMPP Control Panel.
4. Buka peramban web dan akses alamat: `http://localhost/perpus-app`
